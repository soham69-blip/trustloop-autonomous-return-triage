# TrustLoop Return & Refund Policy

## 1. Standard Return Window

Customers may request a return within 30 calendar days of delivery.

Returns requested after 30 days are normally outside the standard return window and require manual review.

## 2. Product Condition

Returned products should be unused, undamaged, and include the original packaging and required accessories.

Products showing clear signs of intentional use, damage, or missing essential components may require manual review.

## 3. High-Value Products

High-value products may require additional verification before a refund is approved.

Additional verification can include order information, account history, return reason, and photographic evidence.

## 4. Multiple Accounts

Returns involving multiple customer accounts associated with the same user or suspicious account relationships require additional review.

Multiple-account activity alone does not automatically prove fraud.

## 5. Discounted Orders

Products purchased using discounts or promotional offers remain eligible for return when all standard return conditions are satisfied.

Use of a discount alone is not sufficient evidence of fraud or abuse.

## 6. Return Reasons

The stated return reason should be consistent with the condition of the returned product and available evidence.

Inconsistent or suspicious return information should be escalated for additional review.

## 7. Repeated Returns

Customers with repeated return activity may require additional review.

Historical return behavior should be evaluated together with the current return case.

## 8. Refund Decision

A return may be automatically approved when:

- The return is within the permitted window.
- The product is eligible.
- No significant risk indicators are present.
- Available evidence is consistent with the return request.

A return may be automatically rejected only when there is sufficient evidence that the request violates an applicable policy rule.

Cases with conflicting, incomplete, or ambiguous evidence should be escalated to a human reviewer.

## 9. Human Escalation

Human review is required when:

- The return is outside the standard return window.
- Evidence is incomplete or contradictory.
- Multiple-account activity requires investigation.
- Product condition cannot be reliably verified.
- High-value merchandise requires additional verification.
- The available information is insufficient for a confident automated decision.

## 10. Important Decision Principle

No single feature should automatically determine that a customer is fraudulent.

TrustLoop should combine:

- Machine-learning risk signals
- Return-policy rules
- Customer/account history
- Return metadata
- Evidence analysis

before producing a final decision.

The final decision must be one of:

- AUTO_APPROVE
- AUTO_REJECT
- HUMAN_ESCALATION
